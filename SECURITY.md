# Security Policy

## Supported versions

Until the project reaches 1.0, security fixes are made on the latest released 0.x version only.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/perbellinioa/pi-copilot-model-discovery/security/advisories/new). Include:

- Affected version or commit
- Reproduction steps
- Expected impact
- Any suggested mitigation

Do not include API keys, OAuth tokens, private tenant catalogs, session files, cache files, or other credentials. If private reporting is temporarily unavailable, contact the maintainer through the GitHub profile without sending sensitive details until a private channel is established.

Reports will be acknowledged as soon as practical. Confirmed issues will be investigated privately, fixed on the supported release line, and disclosed after a remediation is available.
